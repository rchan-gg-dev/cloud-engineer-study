Linux command practice
[現在地・ディレクトリ操作]

pwd
 現在いる場所を表示

ls
現在いる場所のファイルやディレクトリを表示
-l:詳細情報（権限・所有者・サイズなど）を表示
-a:隠しファイルも含めて表示

cd
ディレクトリを移動　
cd ..:１つ上のディレクトリへ移動
cd ~ :ホームディレクトリへ移動


mkdir
ディレクトリを作成

rmdir
空のディレクトリを削除

[ファイル操作]

touch
ファイルを作成

cat
ファイル内容を表示

cp
ファイルやディレクトリーをコピー

mv
ファイルやディレクトリを移動・名前変更

rm
ファイルを削除

head
ファイルの先頭部分を表示 
-n 行数:指定した行数を表示

tail
ファイルの末尾部分を表示
-n 行数:指定した行数を表示

echo
文字列を画面に表示
>:出力をファイルへ書き込む（既存内容は上書き）
>>:出力をファイルの末尾へ追記

[ファイル編集]

nano
ターミナル上でテキストファイルを編集
Ctrl + O:保存
Ctrl + X:終了

[ユーザー情報]

whoami
現在ログインしているユーザー名を表示

id
ユーザーID、グループID、所属グループなどを表示

groups
現在のユーザーが所属しているグループを表示

[権限・所有者]

chmod
ファイルやディレクトリの権限を変更

権限：
r = read（読み取り）
w = wirte（書き込み）
x = execute（実行）

対象：
u = 所有者（user）
g = グループ（group）
o = その他（other）

例：
chmod u+x file
所有者に実行権限を追加

chmod u-x file
所有者から実行権限を削除

数値指定：
r = 4
w = 2
x = 1

600 = rw-------
644 = rw-r--r--
755 = rwxr-xr-x

chmod
ファイルやディレクトリの所有者を変更

chgrp
ファイルのディレクトリのグループを変更

sudo
管理者権限でコマンドを実行
※実行内容を確認してから使用する

[シェルの基本]

&
コマンドをバックグラウンドで実行

|
左側のコマンドの出力を右側のコマンドへ渡す

grep
指定した文字列を検索
