Linux Service / Log Commands

[サービス確認]

systemctl status <サービス名>
サービスの詳細な状態を確認
active (running) : 正常に動作中
failed           : 起動失敗・異常終了など

systemctl is-active <サービス名>
サービスが現在動作しているか簡単に確認

[ログ確認]

journalctl
systemdが収集しているログを表示

journalctl -u <サービス名>
指定したサービスのログを表示

-n 行数
最新の指定行数を表示

--no-pager
ページャーを使わず、そのままターミナルに表示

-p err
errorレベル以上のログに絞る

-b
今回のOS起動以降のログに絞る

[ログファイル]

/var/log
Linuxでログファイルが保存される代表的なディレクトリ

例：
/var/log/dpkg.log
パッケージのインストール・更新などの記録

tail -n 20 <ログファイル>
ログの末尾20行など、最近の記録を確認するときに使用

[障害調査の基本]

1. 問題が起きているサービスを確認
2. systemctl status で状態を確認
3. failed やエラー表示がないか確認
4. journalctl -u で対象サービスのログを確認
5. エラーや異常が発生した時刻付近を調べる

[現時点での重要ポイント]

サービスの状態確認
→ systemctl status

サービスのログ確認
→ journalctl -u

Linuxのログ保存場所
→ /var/log

障害対応では
「状態を見る → ログを見る → 原因を絞る」
という流れを意識する
